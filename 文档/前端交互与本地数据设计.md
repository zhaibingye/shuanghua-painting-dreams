# 霜华绘梦前端交互与本地数据设计 v2

## 1. 产品形态

应用由“图片工作台 / 视频工作台 / 历史页”升级为统一对话式创作界面。

```text
┌─────────────────┬──────────────────────────────────────────┐
│ 261px 对话侧栏   │ 顶栏：对话标题 / API 格式 / 模型 / Key  │
│                 ├──────────────────────────────────────────┤
│ + 开启新对话     │                                          │
│ 搜索 / 类型筛选  │              消息流                      │
│ 今天             │      用户消息 / 图片 / 视频任务          │
│ 过去 7 天        │                                          │
│ 更早             │                                          │
│                 ├──────────────────────────────────────────┤
│ 设置             │     24px 圆角浮动对话输入框              │
└─────────────────┴──────────────────────────────────────────┘
```

设计 Token、主题、圆角、间距、排版和动效遵守 `DS设计语言.MD`。

## 2. 路由

```text
/                      欢迎页
/chat/:conversationId  对话页
```

历史即对话列表，不再提供独立历史路由。设置使用模态弹窗，本轮参数使用右侧抽屉。

## 3. 对话创建

创建弹窗选择：

- 图片 / 视频。
- API 格式。
- 模型 ID。

创建时保存当前格式 Base URL 快照。对话建立后格式、Base URL 和模型固定，避免破坏原生上下文。

默认图片格式：`openaiResponsesImage`。  
默认 Responses 主体模型：`gpt-5.6-luna`。

## 4. 对话侧栏

功能：

- 新建对话。
- 全部 / 图片 / 视频筛选。
- 标题和模型搜索。
- 今天 / 过去 7 天 / 更早分组。
- 重命名。
- 删除对话及关联本地媒体。
- 打开设置。

移动端侧栏变为抽屉，并使用遮罩关闭。

## 5. 消息结构

### 5.1 用户消息

显示：

- 文本。
- 本地图片缩略图。
- 公网图片 URL 缩略表示。

用户本地图片保存为 Blob，不保存 Data URL。

### 5.2 图片助手消息

可能包含：

- 流式状态。
- 当前 Partial Image。
- 最终图片网格。
- 普通文本回复。
- Gemini 思考折叠区。
- `revisedPrompt`。
- 下载、查看、设为编辑基图、遮罩编辑。
- 失败、停止、中断状态。

### 5.3 视频助手消息

显示：

- 提交、排队、生成、查询错误、终态。
- 进度条。
- HTML5 视频播放器。
- 任务 ID、模型。
- 复制 URL、打开、显式续写。

## 6. 浮动输入框

- 最大宽度跟随消息流（840px / 712px）。
- Textarea 自动增高，最大 240px。
- Enter 发送，Shift+Enter 换行。
- 本地图片和图片 URL 附件。
- 本轮参数入口。
- OpenAI Images 遮罩入口。
- 发送按钮在流式期间变为停止按钮。

## 7. 图片对话交互

### 7.1 OpenAI Images / xAI

```text
首次轮次：
  无附件 → 生图
  有附件 → 编辑

后续轮次：
  活动最终图片 + 本轮新附件 → 编辑
```

- 每轮第一张非思考最终图自动成为活动图。
- 多结果时用户可以点“设为基图”。
- 想重新从零生成时创建新对话。

### 7.2 OpenAI Responses

- 完整成功历史保存在 IndexedDB。
- 发送前临时把历史 Blob 转为 Data URL。
- 重建 `message` 与 `imageGenerationCall` 项。
- 不使用 `previous_response_id`。
- `store: false`。
- 文本与图片都可流式呈现。

### 7.3 Gemini

- 回传完整成功历史。
- 保留模型 parts 顺序。
- 保留 `thoughtSignature`。
- `includeThoughts` 开启时显示折叠思考区。
- 思考图片会本地保存以支持下一轮，但不会成为活动基图。

## 8. SSE 与 Partial Images

参数：

```text
partialImages: 0 | 1 | 2 | 3
默认：2
```

规则：

1. 图片流由全局内存任务管理器持有，切换对话不取消请求。
2. OpenAI Images 的 `partialImages` 仅作用于无参考图的文生图；参考图与遮罩编辑使用上游非流式请求，只通过本站 SSE 返回最终完成事件。
3. Partial 按 `imageIndex` 保存最新预览，多结果的预览不会互相覆盖。
4. 同一 `imageIndex` 的新 Partial 到达后替换旧 Blob，由展示组件释放旧 Object URL。
5. Partial 不写入 IndexedDB、不出现在历史结果中、不作为编辑基图。
6. `image.partial` 与 `image.completed` 使用不同事件类型，预览不会进入最终 Assets。
7. 最终图到达后由 Worker 转 Blob。
8. `turn.completed` 后原子持久化。
9. 用户显式停止或请求失败时释放 Partial；切换对话只解除当前页面展示。
10. 刷新或关闭浏览器仍会中断图片任务，本版本不恢复跨页面生命周期请求。

## 9. 本轮参数抽屉

图片参数：

- Gemini：比例、图片大小、输出模态、Thinking Level、Include Thoughts。
- OpenAI Images：数量、尺寸、质量、格式、压缩、背景；文生图显示 Moderation 与 Partial Images，参考图/遮罩编辑显示 Input Fidelity 与非流式说明。
- OpenAI Responses：尺寸、质量、格式、压缩、背景、Moderation、Input Fidelity、Partial Images。
- xAI：数量、比例、分辨率、质量。

视频参数：

- 生成模式和对应素材字段。
- 时长、分辨率、比例。
- 音频、水印、尾帧、Seed、Web Search 等能力项。
- Seedance 2.0 不显示服务等级，因为上游要求省略字段。

参数修改会更新当前格式的默认值，但不改变对话模型与连接。

## 10. 遮罩编辑

仅 OpenAI Images 提供。

可用条件：

- 已有活动生成图，且本轮没有其他附件；或
- 首轮只有一张本地输入图。

导出规则：

- PNG RGBA。
- 与原图尺寸一致。
- 涂抹区 Alpha=0。
- 保留区 Alpha=255。

## 11. 视频轮次

每轮默认独立，提交成功后立即清空草稿。

### 字节显式续写

- 原任务成功并存在 `lastFrameUrl`。
- 点击续写后进入首帧生视频模式。
- `parentTaskId` 建立本地关系。

### xAI 显式扩展

- 当前模型为 `grok-imagine-video`。
- 原任务成功并存在 `videoUrl`。
- 点击后进入 extension 模式。

## 13. IndexedDB v2

数据库：

```text
shuanghua-workspace
```

对象仓库：

```text
conversations
messages
assets
videoTasks
```

### 13.1 Conversation

```ts
interface StoredConversation {
  id: string;
  title: string;
  mediaKind: "image" | "video";
  apiFormat: ApiFormat;
  baseUrl: string;
  modelId: string;
  activeImageAssetId: string | null;
  createdAt: string;
  updatedAt: string;
}
```

### 13.2 Message

```ts
interface StoredMessage {
  id: string;
  conversationId: string;
  role: "user" | "assistant";
  mediaKind: "image" | "video";
  status: "pending" | "streaming" | "succeeded" | "failed" | "stopped" | "interrupted";
  text: string;
  attachmentAssetIds: string[];
  outputAssetIds: string[];
  providerState: GeminiState | OpenAIResponsesState | null;
  optionsSnapshot: Record<string, unknown>;
  taskId: string | null;
  error: StoredTaskError | null;
  createdAt: string;
  updatedAt: string;
}
```

### 13.3 Asset

Blob 与 URL 使用互斥字段：

```ts
interface StoredMediaAsset {
  id: string;
  conversationId: string;
  messageId: string;
  role: "input" | "output";
  blob: Blob | null;
  url: string | null;
  mimeType: string | null;
  width: number | null;
  height: number | null;
  revisedPrompt: string | null;
  thought: boolean;
}
```

### 13.4 删除事务

删除对话时在一个事务中删除：

- Conversation。
- 所有 Message。
- 所有 Asset Blob。
- 所有本地 VideoTask。

不会调用上游删除接口。

## 14. 可访问性与响应式

- 所有输入使用 Label。
- 图标按钮具有 `aria-label`。
- Dialog 管理焦点。
- 状态不只依赖颜色。
- 移动端侧栏、设置、参数面板可键盘和触摸操作。
- 动画遵守 `prefers-reduced-motion`。

## 15. 验收

- 可以创建、搜索、重命名和删除多个对话。
- 默认 Responses 模型为 `gpt-5.6-luna`。
- Partial Images 默认 2，可选择 0～3。
- 停止按钮能取消指定图片 SSE。
- 图片任务在不同对话间切换时继续运行，返回原对话可看到预览或最终结果。
- 刷新后已完成的最终图片和对话恢复；刷新时仍在运行的图片任务标记为中断。
- Gemini 签名和完整历史恢复。
- 视频任务切换页面后仍轮询。
- Seedance 2.0 参数面板没有服务等级。
- 桌面和移动端 E2E 关键流程通过。
