> 部署目标：Linux + 宝塔/Nginx + PM2，单机，无 Docker

```text

    application/             image_service / video_service
```

## 4. 后端实施要点

### 4.1 图片对话流

```http
POST /api/v1/images/conversation-turns/stream
```

- Route 返回 `StreamingResponse`。
- Application Service 按判别联合分派 Adapter。
- Provider 事件统一成产品 SSE 事件。
- 流建立后的异常转为 `turn.failed`。
- FastAPI 流断开仍会取消对应上游连接；前端通过应用级任务协调器避免路由切换造成断开，只有显式停止、刷新或关闭浏览器才终止连接。

### 4.2 SSE Transport

上游图像 Base64 可能位于数 MB 的单个 `data:` 行中，因此禁止使用存在行长限制的 `readline()`。

实现要求：

- `iter_any()` 读取字节块。
- 增量 UTF-8 Decoder。
- 在累计字符串缓冲中查找空行事件边界。
- 处理 CRLF 与 LF。
- 支持多行 data。
- 强制响应总大小上限。

### 4.3 OpenAI Responses

固定：

```json
{
  "store": false,
  "stream": true,
  "tool_choice": { "type": "image_generation" }
}
```

不得发送 `previous_response_id`。历史由浏览器显式提供。

### 4.4 Seedance service_tier

Adapter 不能仅根据表单默认值无条件发送字段。

```python
capabilities = byte_dance_model_capabilities(model_id)
if capabilities.get("serviceTierParameter") is True:
    payload["service_tier"] = options.service_tier
```

必须测试 `doubao-seedance-2-0-260128` payload 中不存在 `service_tier`。

## 5. 前端实施要点

### 5.1 数据事务

- 创建用户消息、助手占位消息、输入附件和视频任务：单事务。
- 图片最终完成：最终 Assets、助手消息、Provider State、活动图片：单事务。
- 删除对话：Conversation、Messages、Assets、VideoTasks：单事务。

### 5.2 Base64 生命周期

```text
上游 SSE Base64
  → Worker Blob
  → IndexedDB Blob
```

禁止：

- Base64 写 LocalStorage。
- Base64 写 IndexedDB 请求快照。
- Partial Image 写 IndexedDB。

### 5.3 Object URL

以下时机必须释放：

- Partial 被下一张 Partial 替换。
- 流完成、失败、停止。
- 附件被删除。
- 对话切换。
- 组件卸载。
- 遮罩编辑器关闭。

## 9. Nginx

整个域名代理到 FastAPI：

```nginx
location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    proxy_connect_timeout 30s;
    proxy_send_timeout 620s;
    proxy_read_timeout 620s;

    proxy_request_buffering off;
    proxy_buffering off;
    gzip off;
}

client_max_body_size 128m;
```

SSE 路径不能启用代理缓存、响应缓冲或会合并事件的压缩策略。
