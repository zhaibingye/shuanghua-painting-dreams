# 前端适配与交互优化

日期：2026-10-21

## 视觉与布局

沿用原有冷蓝设计语言，重新组织首页的标题、图片与视频入口、抽象场景插画和信息层级。插画由 CSS 绘制，不依赖外部图片或字体服务。统一圆角、焦点、表单、导航选中态和触屏操作尺寸，适配浅色与深色主题。

| 区域 | 调整 |
| --- | --- |
| 全局工作区 | 使用动态可视高度，响应浏览器工具栏、屏幕旋转和软键盘；保留缩放并考虑安全区域 |
| 桌面导航 | 1024px 起常驻，宽度在 248–288px 之间随屏幕变化，主内容通过 minmax(0, 1fr) 收缩 |
| 手机导航 | 模态抽屉，背景不可交互；支持 Escape、焦点约束与恢复，切换到桌面后释放模态状态 |
| 聊天布局 | 消息独立滚动，输入区正常占位，移除绝对定位和固定底部留白 |
| 输入区 | 文本随内容和宽度调整高度，长文本内部滚动；发送按钮保留在工具栏 |
| 弹窗与面板 | 创建对话、设置、Key 引导、参数、遮罩共用可视高度约束；内容独立滚动 |
| 表单与媒体 | 窄屏表单可收缩，手机输入字体 16px，长文本和任务 ID 可换行，媒体不会撑开消息流 |

## 交互修复

- 用户向上阅读历史时，不再因预览、文本或新消息变化而被拉回底部；可通过按钮回到最新消息。
- 图片尺寸和输入区高度变化后，跟随底部的用户仍能看到最新内容。
- 侧栏操作在触屏上可见，菜单可通过外部点击和 Escape 收起；搜索状态在断点切换时保留。
- 通过路由匹配识别正在查看的对话，删除后返回首页。
- 创建对话时同步防重复提交，存储失败后保留弹窗并反馈错误。
- 图片准备和视频提交阶段显示真实的等待状态，仅可取消的图片任务提供停止按钮。
- 附件处理完成前禁止发送；混合文件批次失败不创建预览 URL，离开对话后丢弃迟到结果。
- 附件返回时重新检查当前数量上限并保留已有附件；任务运行时禁用已经展开的 URL 编辑区。
- 增加弹窗说明、按钮名称、跳到主内容入口，以及随主题更新的浏览器栏颜色。
